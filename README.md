# 视频截图工具

一个基于C#和FFmpeg的视频处理工具，支持按指定时间间隔生成视频截图、视频剪辑和截图重命名等功能。

## 功能特性

- 📸 **按时间间隔截图**：支持自定义时间间隔生成视频截图
- ⚡ **硬件加速**：使用FPS滤镜和硬件加速提高截图效率
- ✂️ **视频剪辑**：支持删除视频中间段（分段提取合并法）
- 📝 **智能重命名**：自动为截图文件添加时间后缀
- 🌓 **主题切换**：支持明亮/黑暗主题切换
- 💾 **配置保存**：自动保存用户配置
- 📋 **详细日志**：完整的操作日志记录

## 系统要求

- Windows 10/11 64位
- .NET 6.0 运行时
- FFmpeg 8.0.1 或更高版本

## 安装说明

1. 下载并安装 [.NET 6.0 运行时](https://dotnet.microsoft.com/zh-cn/download/dotnet/6.0)
2. 下载 [FFmpeg](https://ffmpeg.org/download.html) 并解压到本地目录（如 `C:\ffmpeg-8.0.1-essentials_build`）
3. 下载本项目的可执行文件或从源代码编译

## 使用方法

### 1. 生成视频截图

1. 点击「浏览...」选择要处理的视频文件
2. 设置截图时间间隔（秒）
3. 点击「浏览...」选择输出路径
4. 点击「使用FPS滤镜生成截图 (硬件加速)」按钮
5. 等待处理完成，截图将自动保存到指定路径

### 2. 直接重命名截图文件

当你已经有了截图文件，想要按照时间间隔重命名时：

1. 选择原始视频文件（用于获取文件名）
2. 设置正确的时间间隔
3. 选择包含截图文件的输出路径
4. 点击「直接重命名截图文件」按钮
5. 工具将按照时间间隔自动重命名截图文件

### 3. 视频剪辑（删除中间段）

1. 选择要处理的视频文件
2. 设置要删除的开始时间和结束时间（格式：HH:MM:SS 或 秒数）
3. 选择输出路径
4. 点击「删除中间段 (分段提取合并法)」按钮
5. 等待处理完成，剪辑后的视频将保存到指定路径

## 配置说明

- 默认时间间隔

## 技术实现

### 核心技术

- **C# .NET 6.0**：主程序开发语言
- **Windows Forms**：GUI界面框架
- **FFmpeg**：视频处理核心组件

### 关键功能实现

1. **截图生成**：使用FFmpeg的FPS滤镜，每N秒生成一帧
   ```
   ffmpeg -hwaccel auto -i "input.mp4" -vf fps=1/N -q:v 2 -an "output_%04d.jpg"
   ```

2. **视频剪辑**：采用分段提取合并法
   - 提取前半段（0 → 开始时间）
   - 提取后半段（结束时间 → 视频末尾）
   - 使用FFmpeg concat demuxer合并两段视频

3. **文件重命名**：根据时间间隔自动生成带时间后缀的文件名
   - 格式：`视频名_HHmmSS.jpg`
   - 支持多种命名模式兼容

## 编译说明

1. 克隆或下载项目源代码
2. 使用 Visual Studio 2022 或更高版本打开项目
3. 安装所需的NuGet包（如果有）
4. 选择「调试」或「发布」配置
5. 点击「生成」菜单 → 「生成解决方案」
6. 编译后的文件将输出到 `bin/Debug/net6.0-windows/` 或 `bin/Release/net6.0-windows/` 目录

## 注意事项

1. 确保FFmpeg路径正确：工具默认使用 `C:\ffmpeg-8.0.1-essentials_build\bin\ffmpeg.exe`，如果你的FFmpeg安装在其他位置，需要修改源代码中的路径
2. 处理大型视频文件可能需要较长时间，请耐心等待
3. 确保有足够的磁盘空间存储临时文件和输出文件
4. 工具仅支持Windows系统
